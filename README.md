# SUAS Shopify Theme

This folder is the Shopify theme source for SUAS.

Connect this repository/branch to Shopify through Online Store > Themes > Add theme > Connect from GitHub.

Shopify expects these folders at the repository root:

- assets
- blocks
- config
- layout
- locales
- sections
- snippets
- templates

Do not upload the ZIP files to GitHub for the Shopify integration. Upload/commit the folders themselves.
